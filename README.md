# Quimicos-2A-S.A.
La página web de Bolívar Clean contiene cuatro secciones principales: Inicio, donde se presenta la empresa, su misión, visión y productos; Empresas, con información sobre Clorox, Lysol y Palmolive; Productos, con los nombres, precios y existencias de los productos de limpieza; e Información, con los datos de contacto y redes sociales de la empresa.
